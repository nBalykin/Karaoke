Обновить index.html

Создай несколько песен на вкладке «Новая песня» — каждая скачанная песня попадает в очередь ниже. Когда очередь готова, загрузи index.html один раз — все песни из очереди добавятся сразу, список отсортируется по алфавиту (сначала по исполнителю, затем по названию).

Инструкция
  1. На вкладке Новая песня — заполни и скачай столько песен, сколько нужно. Каждая попадёт в очередь
  2. Положи все скачанные файлы в karaoke-site/songs/
  3. Перетащи karaoke-site/index.html сюда — все песни из очереди добавятся разом и список пересортируется по алфавиту
  4. Скачай обновлённый index.html и замени им старый
  5. git add . → git commit → git push
